Everything else on this site describes how PRISM is designed to work. This page
describes what actually exists today.

## What has happened

| | |
|---|---|
| Loans originated | Zero |
| Capital deployed | Zero |
| Pools funded | Zero |
| Losses | Zero, because there have been no loans |
| Network | Solana devnet only — three tranches running |

## What has not happened

- No originator signed.
- No credit investor signed.
- No security audit.
- No legal entity incorporated.

## The team

Four engineers, India-based, funded by roughly \$14,500 in grants. No salaries.
