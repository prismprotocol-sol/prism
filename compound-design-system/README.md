# Compound Landing Page Recreation

This folder defines the visual and interaction system for recreating the supplied Compound Technology Partners landing page.

## Purpose

This is a **design-system specification first**, not an implementation brief.

The next agent should use these files to establish the visual language, tokens, layout grammar, typography, image treatment, interaction model, and section architecture before writing Next.js code.

## Source of truth

Use the supplied screenshots/video as the visual source of truth.

Do not invent a different visual direction.

The target is a black, editorial, technical, grid-driven AI consultancy site with:
- luxury editorial typography
- brutalist/Swiss grid discipline
- microscopic technical UI details
- degraded halftone photography
- extremely restrained motion
- asymmetry inside a rigid layout system

## Files

- `01_DESIGN_SYSTEM.md` - complete visual system
- `02_TYPOGRAPHY.md` - type hierarchy and font direction
- `03_LAYOUT_GRID.md` - grid, spacing, section geometry
- `04_COLOR_TEXTURE.md` - palette, borders, textures, image treatment
- `05_MOTION_INTERACTION.md` - animation and interaction system
- `06_COMPONENT_SYSTEM.md` - reusable component architecture
- `07_PAGE_ARCHITECTURE.md` - page/section structure and content
- `08_VISUAL_QA.md` - fidelity checklist

## Important

Do not start implementation yet.

First turn this system into a coherent implementation plan, identify any uncertainties from the reference, and preserve the design language exactly.
