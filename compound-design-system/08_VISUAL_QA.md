# 08 — Visual QA Checklist

Before calling the recreation complete, inspect the rendered page at the same approximate desktop aspect ratio as the reference.

## Grid

- [ ] Outer border is visible but subtle
- [ ] Vertical grid lines align between sections
- [ ] Horizontal rules are consistently 1px
- [ ] Sections share alignment anchors
- [ ] Asymmetric elements still obey the grid

## Typography

- [ ] Serif feels editorial, not generic
- [ ] Hero is extremely large
- [ ] Hero line-height is tight
- [ ] "your business" is visually distinct/italic
- [ ] Sans headings remain restrained
- [ ] Metadata is tracked and small
- [ ] Secondary copy is visibly muted
- [ ] No accidental boldness

## Hero

- [ ] Timestamp is tiny
- [ ] Logo is centered
- [ ] Nav is quiet
- [ ] Headline dominates
- [ ] Info strip is a continuous grid
- [ ] Contact button is square-cornered
- [ ] Hero image is degraded/halftoned
- [ ] Crosshairs exist
- [ ] Image does not look like a normal stock photo

## Images

- [ ] Halftone dots are visible
- [ ] Grain is subtle
- [ ] RGB artifacts are restrained
- [ ] Images are darker than typography
- [ ] Image crops resemble the reference
- [ ] No excessive blur
- [ ] No generic AI image treatment

## Services

- [ ] Three cards have asymmetric geometry
- [ ] Cards remain readable over imagery
- [ ] Decorative icons are thin
- [ ] Number labels are small
- [ ] Bottom metadata bars are present

## Logos

- [ ] 5-column desktop grid
- [ ] monochrome
- [ ] restrained logo sizing
- [ ] thin cell borders
- [ ] "AND HUNDREDS MORE" centered

## Security

- [ ] Dark diagonal texture exists
- [ ] Cards look like photographic plates
- [ ] Image framing is visible
- [ ] Number labels are present
- [ ] Cards are asymmetrically positioned

## CTA

- [ ] Large black space
- [ ] Centered logo
- [ ] Large sans-serif heading
- [ ] Square CTA
- [ ] Arrow interaction is subtle

## Motion

- [ ] Entrances are slow
- [ ] No bounce
- [ ] No excessive scaling
- [ ] Image movement is almost subliminal
- [ ] Hover states are restrained
- [ ] Reduced motion is respected

## Final question

Does this look like a premium editorial technology company?

Or does it look like a normal SaaS template with dark colors?

If the latter, the implementation is not finished.
