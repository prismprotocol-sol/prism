# 01 — Compound Visual Design System

## 1. Design thesis

The visual language is built around a contradiction:

**extreme typographic elegance + extremely technical interface structure + chaotic degraded imagery.**

The page should feel:
- intelligent
- expensive
- architectural
- cinematic
- slightly mysterious
- precise
- experimental
- enterprise credible

It should NOT feel:
- like a generic SaaS template
- like a Web3 landing page
- like a futuristic neon AI website
- like a conventional consulting website
- like a portfolio full of random effects

## 2. Core principles

### Precision
Everything aligns to a grid. Borders and baselines matter.

### Restraint
Motion, color, shadows and decoration are intentionally limited.

### Contrast
Large elegant serif typography sits against technical sans/mono UI text.

### Materiality
Photography is treated as physical/digital material: dithering, halftone, grain, color-channel artifacts and low-resolution texture.

### Asymmetry
The underlying grid is rigid, while cards/images deliberately occupy unexpected positions.

### Black space
Black is not empty. It is an active compositional material.

## 3. Visual ratio

Approximate visual distribution:

- 70–85% black/near-black canvas
- 10–20% white/off-white typography and lines
- 0–10% image-derived colors

Color should almost never be introduced by UI elements.

## 4. Shape language

Use:
- rectangles
- squares
- thin rules
- brackets
- crosses
- grids
- circles only for technical icons

Avoid:
- rounded rectangles
- pills
- bubbles
- soft cards
- excessive shadows

Default border radius: `0`.

## 5. Surface language

Panels can use:
- #000 background
- #101010 / #111111 translucent-black surfaces
- subtle image underneath
- very subtle grain

They should feel like dark photographic plates mounted onto a technical grid.

## 6. Density

The site alternates between:
1. huge sparse editorial moments
2. dense technical grid moments
3. chaotic image moments

This rhythm is intentional.

Do not make every section equally dense.
